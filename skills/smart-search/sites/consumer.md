# 产品与口碑

本站点组统一使用共享 session/profile `default`；每条 Camoufox 操作带 `--persistent`。入口常量见 [site-catalog.json](../site-catalog.json)。购物与讨论页面只做搜索/读取；报价、评价和热度均记录观察时间及实际样本范围。

| 站点 | session / profile | 搜索入口 |
|---|---|---|
| 豆瓣 | `default` | `https://search.douban.com/movie/subject_search?search_text={keyword}`；其他类别见下文 |
| 什么值得买 | `default` | `https://search.smzdm.com/?c=home&s={keyword}&v=b` |
| 京东 | `default` | `https://search.jd.com/Search?keyword={keyword}&enc=utf-8` |
| 淘宝 | `default` | `https://s.taobao.com/search?q={keyword}` |
| 大众点评 | `default` | `https://www.dianping.com/`，先选城市再使用页面搜索 |
| 虎扑 | `default` | `https://bbs.hupu.com/search?q={keyword}` |
| 即刻 | `default` | `https://web.okjike.com/search?q={keyword}` |

## 豆瓣

- 默认模板搜影视；图书使用 `https://search.douban.com/book/subject_search?search_text={keyword}&cat=1001`。音乐、话题或其他类别从页面对应搜索入口进入，不把影视条目当作全站搜索结果。
- 提取条目名、真实 subject 链接、类别、作者/导演、年份、评分及评价人数。阅读短评/长评时进入条目实际的评价入口，保存评论/评述作者、日期、原文链接与可见正文。
- 条目平均评分、评价人数与本轮读到的评价样本分别记录；片名相同的不同年份/地区版本分开。

## 什么值得买

- 默认搜综合内容；好价、文章、百科等类别与时间/排序通过实际页面切换。排除广告，并区分优惠信息与用户体验文章。
- 提取标题、真实内容链接、作者、发布时间、商品型号、可见价格与优惠条件；进入原文核对券、会员、地区、规格和有效期。
- “历史低价”、投票和评论数量保留站点原标注；过期优惠注明页面实际状态，不输出为当前可购价。

## 京东

- 按页面选择品牌、规格、价格、店铺类别和排序；核对地区/配送设置会不会改变报价与可售范围。
- 保存商品名、真实商品链接、店铺、规格、展示价格/币种、促销条件与可见评价指标；到详情核对目标 SKU 和评论入口。
- 同商品不同规格/店铺分别记录；评价数量、销量类标注和评论样本不互相代替。不自动加购、下单或评价。

## 淘宝

- 用 `default` profile 初始化首页和登录；按实际网页筛选地区、店铺、价格、规格与排序，不拼接口排序码或调用搜索 API。
- 提取商品标题、真实链接、店铺、目标规格、展示价格与优惠条件、页面实际显示的销量/评价字段；在详情核对商品与选定 SKU。
- 保留访问所需的真实链接参数；券后价、会员价和起始价分别标明适用条件。只读取当前可见评价样本。

## 大众点评

- 先选用户指定城市，再通过页面输入店名、商圈或品类；记录最终城市、地区、分类与排序，不默认上海或使用无法核实的城市 ID。
- 从实际结果进入商户页，提取店名、门店链接、地址、品类、评分、人均价、营业信息及页面可见评价。
- 同品牌不同门店分开；综合评分、子项评分与个人评价分别记录。人均价标为站点展示值，不视作固定菜单报价。

## 虎扑

- 搜索帖子关键词，按实际控件限定分区、时间和排序；不能把论坛帖子搜索当作所有内容类型的检索。
- 提取帖子标题、真实主题链接、作者、发布时间、分区和可见回复/推荐数量；进入帖子读取正文及本轮需要的楼层。
- 引用评论保留楼层/作者/时间与主题链接；不同楼层的观点不合并成一个作者观点，不自动回复或推荐。

## 即刻

- 使用固定 `default` profile；页面要求登录时按 browser-guide 处理。搜索后按当前界面的动态、用户、圈子等实际类别切换。
- 提取展示作者、动态/资料/圈子链接、可见正文、发布时间与可见互动指标；展开正文和实际评论区后再引用内容。
- 无限滚动只按搜索预算获取所需样本，不把加载出的片段当作全部搜索结果，不自动点赞、关注或评论。
