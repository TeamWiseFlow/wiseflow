# 17 维 DNA 分析框架

本框架用于分析以及不断提取其他微信公众号优秀作品的风格，逐步累积形成公众号创作的DNA。分析产物必须是三层：

1. **DNA report**：单篇文章的 17 维提取结果。
2. **DNA 文档**：聚合同一个 DNA ID 下全部 report 后形成的规则。
3. **DNA template**：从 DNA 文档推导出的写作模板。

```text
单篇文章 -> DNA report
多个 DNA report + 权重/focus + 用户输入转译 -> DNA 文档
DNA 文档 -> DNA template
```

## 一、选题特征（3）

### 1. 选题角度

- 选题类型
- 选题与受众的关联

分析时必须回答：

- 作者从什么入口选题：现象、问题、故事、数据、政策、产品、行业矛盾还是个人观察。
- 目标读者为什么关心这类选题：理解、判断、行动、避坑、身份认同还是情绪共鸣。

### 2. 标题特征

- 标题类型：例如数字型、反差型、痛点型、悬念型、结论型、问答型。
- 标题原文

### 3. 封面图

封面图来源：

- `wx-mp-hunter fetch <url> --download-cover` 下载文章分享封面。
- 用户手动提供本地图片文件。
- 无法获取封面图时记录“未提供”，不得根据正文图片或标题想象补齐。

Agent 必须通过视觉模型读取封面图，至少提取：

| 特征 | 分析要求 |
| --- | --- |
| 画面主体与场景 | 主体是什么、在做什么、处于什么场景，主体占画面比例 |
| 构图与画幅 | 横竖画幅、主体位置、视觉动线、留白、前景背景层次 |
| 色彩体系 | 主色、辅色、强调色、饱和度、明度、对比关系 |
| 光线与质感 | 自然光 / 人造光、方向、阴影、颗粒、锐度、材质 |
| 风格与媒介 | 摄影 / 插画 / 3D / 拼贴 / 数据图表 / 手绘，具体流派或时代感 |
| 文字视觉与图文关系 | 是否有标题字、字体气质、字号层级、字图遮挡关系 |
| 品牌识别元素 | Logo、固定角标、边框、水印、系列符号、版式惯性 |
| 避免项 | 与该封面风格相反、容易破坏识别度的元素 |

视觉模型分析必须能反推为一套可执行 AIGC 提示词，包含主体、场景、构图、画幅、色彩、光线、质感、风格、文字视觉、品牌元素和负向约束；目标是生成风格高度一致的图片，而不是只写“高级感”“简洁”“专业”等抽象形容词。

## 二、表层特征（4）

### 4. 用词习惯

- 高频词 Top 10-15
- 情绪词偏好

### 5. 词汇与句式

- 词汇复杂度（口语/专业）
- 句长分布（短/中/长）
- 句式类型占比（陈述/疑问/感叹/祈使）

### 6. 句式节奏

- 长短句搭配模式
- 设问自答频率
- 排比/对比使用频率

### 7. 语气与基调

- 朋友式/专业式比例
- 亲密度与距离感
- 人称使用偏好（我/你/我们）

## 三、结构特征（3）

### 8. 段落结构

- 1 句段、2-3 句段、4-6 句段、长段的占比判断
- 开头方式（观点/案例/设问）
- 段内结构（总分总/递进/并列）

### 9. 文章结构模式

- 开头-主体-结尾比例
- 层级深度风格，只分一层、两层，还是会出现多层嵌套
- 分块密度，是密集分块还是连续长文推进
- 分块标题的语气和长度
- 哪类内容会强制分块

### 10. 论证逻辑

- 论证推进（递进/并列/对比/因果）
- 案例类型与长度
- 数据引用方式与频率

## 四、深层特征（4）

### 11. 节奏感

- 信息密度波动
- 快慢节奏切换点
- 关键段节奏模式

### 12. 修辞手法

- 比喻系统
- 对比和重复策略
- 反问/设问触发条件

### 13. 情感表达

- 情绪强度曲线
- 情绪触发词
- 高潮与回落的写法

### 14. 思维特征

- 反直觉表达频率
- 本质追问深度
- 系统性与长期主义倾向

## 五、独特标记（3）

### 15. 专业度体现

- 术语密度
- 行业案例使用密度
- 专业解释方式

### 16. 签名式标记

- 固定句式
- 高频转折词
- 标志性表达片段

### 17. 起承转合微操

- 起：从什么东西起步推进内容：现象、问题、故事、数据还是判断
- 承：每往前推进一层时，靠什么驱动：追问、对比、案例、拆概念、给结论
- 转：靠什么驱动：追问、对比、案例、拆概念、给结论
- 合：收束模式：如何 CTA

## 分析要求

### DNA report 要求

除封面图外，每个维度至少包含：

1. **单篇结论**：这篇文章在该维度上的具体做法。
2. **可复用写作信号**：聚合时值得进入 DNA 文档的信号。

单篇 report 不需要判断跨篇稳定性；这个判断属于 DNA 文档聚合阶段。

封面图的 DNA report 必须记录图片路径、视觉模型分析结果、AIGC 复现提示词要素和无法判断的信息。没有图片时不得编造视觉证据。

### DNA 文档要求

除封面图外，每个维度至少包含：

1. **聚合结论**：当前账号/作者采用的规则。
2. **报告依据**：来自哪些 DNA report、各自权重和 focus。
3. **写作规则**：生产时必须怎么做，避免只写“专业”、“亲切”这类空泛形容词。

聚合时要区分高频共性、高权重样本偏好和用户的明确指示。用户输入必须先映射到具体维度，再转译为聚合结论和写作规则。

封面图聚合时必须输出可复用的视觉生成规则和 AIGC 提示词模板，并说明覆盖多少张封面、哪些元素是共性、哪些是孤例。

样本规则：

- 默认所有 DNA report 权重为 1。
- 用户可指定某篇 report 权重更高，或通过 focus 限制它只影响某些维度。
- 聚合结论必须说明依据，不把统计表直接当结论。
- Agent 必须回读 report 与必要原文，避免只看数值。

## DNA 文档到模板的推导

DNA 文档完成后，必须把可复用结论转成写作模板：

- 选题角度转成选题入口和受众关联要求。
- 标题特征转成标题类型偏好，同时选择代表性标题作为示例直接记录到模板中。
- 封面图特征转成封面风格规则和 AIGC 提示词要素。
- 其余部分按固定语义结构组织为“起、承、转、合、CTA”五个部分。
- 每个部分写明本段任务、切入或推进方式、结构、句式、语气、素材、必须做和避免项。
- 固定的是七个模板部分，不是物理段落数量；任一部分可以对应一个或多个自然段、甚至没有（略过），也可以不出现小标题。
- 每个部分的规则必须能从 DNA 文档的 17 维聚合结论推导，不得引入样本和用户输入之外的新规则。
- 用户输入必须先映射到具体维度，再转译为模板中的执行规则。

七个部分与 17 维的推导关系：

| 模板部分 | 必须吸收的 DNA 维度 |
| --- | --- |
| 选题 | 选题角度、选题与受众关联 |
| 标题 | 标题类型、参考标题、标题语气与结构、封面图风格与 AIGC 提示词要素 |
| 起 | 起承转合微操、选题角度、段落结构、句式节奏、语气与基调、素材或论据 |
| 承 | 起承转合微操、文章结构模式、论证逻辑、用词习惯、词汇与句式、节奏感、专业度体现 |
| 转 | 起承转合微操、修辞手法、情感表达、思维特征、句式节奏 |
| 合 | 起承转合微操、文章结构模式、情绪强度曲线、高潮与回落方式、签名式标记、语气 |
| CTA | 选题与受众关联、语气与基调、词汇与句式 |

## 更新规则

- 新文章先形成单篇 DNA report，再与历史 report 合并重新聚合。
- Agent 需要比较新旧结论：保留共性、记录变化、移动孤例。
- 用户明确指定只参考某一块时，只更新对应维度，其他维度不得静默改写。
- 用户输入必须转译为 affected dimensions、DNA 修改、template 修改和执行规则；原话只保留在转译来源中。
- 更新后 DNA 文档与模板必须同步，避免两者表达两套规则。
