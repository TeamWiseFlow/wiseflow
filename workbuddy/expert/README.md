# 小贝 · 自媒体获客运营专家

小贝（xiaobei）是为OPC/中小微企业量身打造的自媒体获客智能体，现在你可以在workbuddy上直接使用它：

- 微信公众号文章写作、排版与草稿箱上传
- 小红书/小绿书图文创作与发布
- 图文海报生成
- 视频素材剪辑
- 视频多平台分发（支持小红书、快手、tiktok、微博等）
- Twitter/X、微博等平台发文
- 微信朋友圈内容发布（通过企业微信接口）
- 爆款视频追爆分析、仿写与再创作（支持抖音、快手、小红书等平台视频链接）
- 赛道头部账号DNA级复刻（支持小红书、抖音、微信公众号）
- 已发布作品指标记录、内容 DNA 效果分析与复盘
- 自媒体评论区获客
- 通过社交媒体寻找潜在客户或市场调研
- "四声分析"法战略研判与讨论
- 产品deck、ppt制作，投资/IR 材料准备
……

可以从三个问题开始：

### 1. 同赛道账号，直接找十个，把 DNA 拆给我

> 我是做【产品/服务】的，帮我在小红书找10个同赛道账号，逐个提取账号DNA，告诉我该学谁、怎么学。

小贝会按你的产品和客户筛账号，取得真实主页与代表作品，再逐个拆解选题、标题封面、表达结构、视觉风格、业务植入和 CTA。交付**十账号对标表、独立 DNA 文件与模板，以及“该学谁、学什么”**。对标结果还能继续用于你自己的内容生产，实际样本不足会说明。

### 2. 做一组小红书原生卡片，我确认后你直接发

> 给我的【产品/服务】做一组“问答讨论流”小红书卡片，配好标题、正文和话题，我确认后直接发布。

群聊误发单图、问答讨论流三图，小贝都有现成的原生界面模板、头像与出图工具。它会把你的业务信息变成能看的讨论流，交付**真实卡片图片、标题、正文和话题**。你确认后，直接走小红书 API 发布，拿到笔记链接并记入发布记录。

从卡片到发布是同一条流程，你不用拿着一份文案再自己找模板、拼图和复制粘贴。

### 3. 我的公众号哪里不对？看作品，说具体的

> 我的微信公众号是【公众号名/文章链接】，帮我找出定位、内容和获客的问题，给我最该先改的3件事。

小贝会读实际文章和封面，用内容 DNA 分析定位、选题、标题首屏、正文论证、产品连接和行动引导。交付**带文章证据的账号诊断、最优先改的三件事，以及能直接替换的标题、开头或 CTA 样例**。你有后台数据时再结合数据复盘，没有数据就不编造“阅读下降”“转化差”。

公众号诊断以你提供的近期文章链接为样本；只给公众号名时，补充文章链接即可继续。

### 想把采集、发布和获客自动化接起来？找掌柜

### 原有的工具，也一起带过来了

平台专家、内容 DNA、追爆分析、原生卡片、已有视频加工、发布记录、内容校准、BD 获客互动、四声分析、产品 deck 与 IR 材料，以及配图、配音、音乐、素材库和邮件等公共技能，连同**脚本、工作流、模板与素材**一起提供。

你提供的素材可以直接抽段、拼接、配乐、加字幕或做口播轻剪。完整视频从零制作则交给你实际可调用的 WorkBuddy 制作专家/技能，小贝整理 Brief 并接回成片运营。

| 小红书 | 搜索、账号/作品/评论、提醒及媒体下载 | 定位、账号对标、图文/视频 DNA；笔记、封面、群聊误发单图和问答讨论流三图 | 图文与视频 API 发布，确认后返回笔记链接并记录 | Creator 本人指标获取与回填；DNA 基线、趋势及归因复盘 | 评论区需求筛选；已实现的私信与直播文字互动，其他写接口按工具能力执行 |

| 快手 | 搜索、账号/作品/评论、公开直播读取与媒体下载 | 定位、账号对标、DNA、文案包装与已有素材加工 | API 发布，按工具实际支持的媒体类型执行 | 本人作品指标获取与回填、DNA 复盘 | 公开需求筛选；普通互动写入、私信和直播写入暂未实现 |

| Twitter / X | 搜索、账号/作品/评论与媒体下载 | 定位、文字/图文 DNA、账号对标、发文及媒体包装 | API 发文及账号权限支持的长文 | 本人作品指标获取与回填、DNA 复盘 | 评论回复、点赞、转发、收藏、关注；X Chat 目前仅查询会话及加密占位历史，不发送 |

平台 API 需要对应账号授权和凭据；使用官方中转的能力需要 OFB_KEY。X、TikTok、微博在本版导入用户明确授权的 API 会话，快手保留 HTTP 登录，小红书与抖音按各自 API 登录流程操作。已发布、已接收、审核中和结果未知分别记录，结果不明不重发。

### 配套能力，让一次任务接上下一轮运营

| 能力 | 小贝会交付什么 | 使用条件与范围 |
| --- | --- | --- |
| 自动复盘与内容校准 | 支持平台取数、指标入库、账号基线与趋势、DNA 归因报告、下一轮具体修改建议 | 需要 WorkBuddy 当前提供定时/常驻执行能力才安排自动任务；小红书、快手、TikTok、X 可调用已保留的本人取数工具，公众号/抖音后台数据由用户提供。DNA 改动经用户采纳后回写 |
| 视频追爆分析 | 对应 hunter 获取作品与下载，随后转写、抽关键帧，提炼钩子、结构、业务植入与 CTA | 抖音、小红书、快手、TikTok、X、微博的可下载视频；ASR 需要已配置的供应商，不支持 B 站链接 |
| 已有视频素材加工 | 抽段、拼接、片头片尾、配乐/配音混音、字幕、画面集锦、口播轻剪与成片质检 | 用户提供或已取得的视频/录音；从零完整制作交给实际可调用的制作专家/技能 |
| 小红书原生卡片 | 真实群聊误发单图或问答讨论流三图、标题、正文、话题、API 发布和发布记录 | 随包模板、头像、样式与 Chromium 渲染；发布前用户确认内容与目标账号 |
| 配图、封面、配音与补充素材 | 图像生成/编辑、带字封面、TTS、BGM 及素材搜索下载 | 百炼/火山等外部模型、免费素材库和用户素材；模型凭据与额度按所选供应商配置，音乐按实际许可署名 |
| 发布与线索记录 | 作品链接、账号、DNA 关联、实际指标、潜客档案与联络去重 | 统一写入用户工作空间；记录工具不代替平台取数或实际发送 |
| BD 获客与邮件 | 从真实账号和评论筛潜客、整理证据与话术，通过已支持的平台写接口或邮件联络 | 仅发送用户授权的内容与对象；没有接口的动作不补造 |
| 四声分析、产品 deck 与 IR | 四视角决策、HTML 演示及长图/PPTX、投资人材料和跟进档案 | 有真实子任务工具时才独立委托四声；否则明确同会话分析。只使用真实业务资料，不含 OSBI 模块 |

本版整体移除视频号、OSBI 和客服团队管理，也不包含 Camoufox。抖音保留采集、DNA 和制作，发布交付材料；公众号保留全文获取、DNA、写作排版与 API 草稿上传，本人后台数据由你提供。知乎发布、浏览器搜索、录屏和填表未纳入。

业务资料、作品、DNA 和数据库放在你选定的工作空间，凭据单独管理。运行环境需 Node.js 22+、Python 3.10+ 和 Bash，小贝会检查并准备依赖。市场实机预览、平台账号连接和真实发布仍需在你的 WorkBuddy 环境验收。
